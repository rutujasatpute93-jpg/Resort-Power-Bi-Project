# Resort Sales & Customer Analysis

## Project Overview
This project analyzes sample sales, bookings, customer behavior, and profitability for five resorts across Maharashtra from 2021 to 2024 using Power BI.

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- CSV datasets

## Dataset Files
- `sales.csv` — Booking details, revenue, costs, and status
- `customers.csv` — Customer information and segments
- `resorts.csv` — Resort names, locations, and room details
- `targets.csv` — Monthly sales and profit targets

## Dashboard 1: Sales & Customer Analysis
- Total Revenue
- Total Bookings
- Average Booking Value
- Unique Customers
- Monthly Revenue Trend
- Revenue by Resort
- Bookings by Channel
- Bookings by Customer Segment

## Dashboard 2: Profit & Target Analysis
- Total Profit
- Total Cost
- Profit Margin %
- Target Achievement %
- Monthly Profit Trend
- Actual Revenue vs Target
- Profit by Resort
- Room Type Profitability

## Key Skills Demonstrated
- Data cleaning and transformation using Power Query
- Data modeling and relationships
- DAX measures and KPI calculations
- Interactive slicers and visualizations
- Sales and profitability analysis


🎯 Project Purpose

The purpose of this project is to analyze resort sales, customer behavior, booking trends, and profitability across five resort locations in Maharashtra from 2021 to 2024 using Microsoft Power BI.

⚠️ Data Disclaimer
This project uses fictional sample data for educational and portfolio purposes only.
It does not represent actual resort business performance.
